## Redesign objectives

1. Build a premium international B2B export website.
2. Improve desktop, tablet and mobile design.
3. Replace repetitive card-based layouts.
4. Create a clearer visual hierarchy.
5. Improve product discovery.
6. Improve buyer enquiry flow.
7. Use consistent licensed stock or AI-generated images.
8. Remove all public placeholder and draft language before launch.
9. Preserve the existing domain, GitHub repository and GitHub Pages setup.
10. Merge into main only after full review and approval.
